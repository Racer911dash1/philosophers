1. Clone the repository
2. Run "make" to compile the code
3. Execute with ./philo "Number of Philosophers" "Time to die" "Time to eat" "Time to sleep" ["Number of times each Philosopher must eat"]

"Number of Philosophers" is where each philosopher equals to one thread.
And the times are in ms.
Example: `./philo 7 800 200 200 5`

While any amount of Philosophers is possible, it's not reccommended to go further than 200 and even that is stretching it.
